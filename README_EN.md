# Mini Map

Added a minimap to the World interface for the SFS Steam version to improve the gameplay experience.

## Installing

Requires **[UITools](https://github.com/cucumber-sp/UITools)** (1.1.6 or newer) to be installed first.

1. Open the `Mods\` folder inside the game directory.
2. Put `Mini Map.dll` into the game's `Mods` folder
3. Start the game. "Mini Map" should appear in the mod list, and the window should show up
   in the world scene.
